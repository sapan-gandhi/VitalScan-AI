# VitalScan AI — Backend

AI-powered early disease risk prediction API built with **FastAPI**, **scikit-learn**, and **Supabase**.

Predicts risk for:
- 🩺 **Diabetes**
- ❤️ **Heart Disease**
- 🩸 **Hypertension**

## Quick Start

### 1. Clone / unzip and enter the backend folder

```bash
cd backend
```

### 2. Create a virtual environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

```bash
# Copy the example and fill in your Supabase credentials
copy .env.example .env        # Windows
cp  .env.example .env         # macOS/Linux
```

Edit `.env`:
```env
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-anon-or-service-role-key
APP_ENV=development
ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000
```

### 5. Set up Supabase database

1. Go to [supabase.com](https://supabase.com) → your project
2. Open **SQL Editor** → **New Query**
3. Paste the contents of `supabase_schema.sql`
4. Click **Run**

### 6. Train the ML models

```bash
python train_models.py
```

This generates:
- `app/models/diabetes_model.pkl`
- `app/models/heart_model.pkl`
- `app/models/hypertension_model.pkl`

> ⚠️ If you skip this step the API still works using built-in heuristic fallbacks.

### 7. Start the server

```bash
python run.py
```

Server starts at **http://localhost:8000**

### Predict Disease Risk

```
POST /api/v1/predict
Content-Type: application/json
```

Request body:
```json
{
  "age": 45,
  "gender": "male",
  "height": 172,
  "weight": 85,
  "blood_pressure": 135,
  "glucose": 115,
  "cholesterol": 210,
  "smoking_status": false,
  "physical_activity": "low",
  "family_history": true
}
```

> `bmi` is optional — it will be auto-calculated from height and weight.

Response:
```json
{
  "success": true,
  "message": "Prediction generated successfully",
  "data": {
    "diabetes_risk": 0.4200,
    "heart_disease_risk": 0.5500,

      "Given your family history, schedule annual preventive health check-ups.",
      "Stay hydrated — drink at least 8 glasses of water daily.",
```

## Connecting the React Frontend

In your React frontend (`src/services/api.js`), update the base URL:

```js
const BASE_URL = 'http://localhost:8000/api/v1'

// POST /predict
export async function predictDisease(formData) {
  const response = await fetch(`${BASE_URL}/predict`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(formData),
  })
  if (!response.ok) throw new Error('Prediction failed')
  return response.json()
}

// GET /history
export async function getPredictionHistory() {
  const response = await fetch(`${BASE_URL}/history`)
  if (!response.ok) throw new Error('Failed to fetch history')
  return response.json()
}
```

## Risk Level Logic

| Score | Label |
|-------|-------|
| 0.00 – 0.30 | Low |
| 0.31 – 0.60 | Moderate |
| 0.61 – 1.00 | High |

**Overall rule:**
- Any disease score > 0.60 → **High**
- Any disease score > 0.30 → **Moderate**
- All scores ≤ 0.30 → **Low**
