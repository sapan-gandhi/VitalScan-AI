# VitalScan-AI

AI-powered early disease risk prediction system.

Predicts risk for Diabetes, Heart Disease, and Hypertension using ML models.

## Quick Start

See detailed instructions:

**Backend**: [backend/README.md](backend/README.md)

**Frontend**: React + Vite app connects to backend API.

```
cd frontend
npm install
npm run dev  # http://localhost:5173
```

**Full Setup**:
1. Git clone/push done.
2. Backend: Follow backend/README.md (venv, Supabase, train, run on :8000).
3. Frontend: npm dev.

## Tech Stack
- Backend: FastAPI, scikit-learn, Supabase
- Frontend: React, Vite, Tailwind, Recharts
- Deployment: Ready for Vercel/Netlify (frontend), Render (backend)
